Abstract

Money laundering in cryptocurrency systems exhibits complex relational and temporal patterns that are difficult to capture using traditional rule-based and feature-based machine learning techniques. Blockchain transactions naturally form large-scale directed graphs, where illicit behavior is often characterized by multi-hop flows, layering, and cyclic movement of funds. Graph Neural Networks (GNNs) provide a principled framework for modeling such relational structures by learning representations that jointly encode node attributes and graph topology.

This project investigates explainable and temporal GNNs for detecting illicit Bitcoin transactions using the Elliptic dataset. A feature-based and static GraphSAGE baseline is first established, followed by a proposed extension incorporating temporal modeling, edge-aware message passing, and subgraph-level explainability. The objective is to develop a reproducible and interpretable AML framework aligned with real-world financial compliance requirements.

Introduction

Anti-Money Laundering (AML) in cryptocurrency networks is challenging due to pseudo-anonymity, high transaction velocity, and complex fund flow structures. Traditional AML systems rely on rules and tabular features, which struggle to detect laundering typologies such as smurfing, layering, mixing, and cyclic transfers.

Bitcoin transaction data naturally forms a directed graph. Suspicious behavior is often defined by relational patterns rather than isolated feature anomalies. Graph Neural Networks are therefore a natural modeling choice, as they can capture multi-hop dependencies and structural context.

This project uses the Elliptic benchmark to study static and temporal GNN-based AML detection, with a strong emphasis on interpretability for regulatory compliance.

Literature Survey

Graph-Based AML and Network Analytics

Network analytics has been shown to be crucial for AML, as laundering is fundamentally a relational process. The systematic review by Deprez et al. (2024) highlights the limitations of static graph representations and motivates temporal and relational learning.

Elliptic Dataset and Explainable GNNs

Lawal et al. (2024) apply explainable GNNs to the Elliptic dataset, demonstrating that graph structure improves detection over feature-only models and that subgraph-level explanations are essential for regulatory transparency.

GNNs for Cryptocurrency AML

Ferretti et al. (2025) compare GCN, GAT, and GraphSAGE models for cryptocurrency AML, confirming the value of relational learning and the inductive capability of GraphSAGE.

Temporal and Heterogeneous Financial Graphs

Xu et al. and recent bank-scale studies show that laundering patterns are sequential and relation-specific, motivating temporal and edge-aware GNN architectures.

Research Gap

Public Elliptic-based studies largely rely on static homogeneous GNNs, while industrial systems use temporal and heterogeneous models that are not reproducible. Few works integrate temporal modeling, edge semantics, and explainability in a unified public benchmark framework.

Dataset Description

The Elliptic dataset contains 203,769 Bitcoin transactions and 234,355 directed edges across 49 temporal snapshots. Each node has 166 anonymized features and is labeled as licit, illicit, or unknown. The dataset is highly imbalanced, reflecting real-world AML conditions.

Transactions are modeled as nodes, fund flows as edges, and time is represented via snapshot indices, enabling temporal graph construction.

Baseline Models and Prototype

Logistic Regression

A feature-only, class-weighted Logistic Regression model establishes a non-graph baseline and provides an interpretable reference.

Static GraphSAGE

A GraphSAGE model aggregates neighborhood information to learn relational representations. Evaluation using PR–AUC shows comparable performance to the strong feature baseline, motivating more expressive temporal and semantic modeling.

Proposed Methodology

Temporal Modeling

A Temporal GNN is proposed to capture sequential laundering patterns such as rapid fan-out and delayed consolidation.

Edge-Aware Message Passing

Transaction amounts, directions, and time gaps are incorporated as edge features, enabling the model to distinguish between different financial behaviors.

Explainability

Subgraph-based explainers (e.g., GNNExplainer) are integrated to identify influential neighbors and temporal paths, ensuring auditability.

Experimental Setup and Evaluation

Models are trained using temporally ordered splits and evaluated with Precision–Recall curves, PR–AUC, and Precision@K to reflect operational AML requirements. Controlled comparisons isolate the impact of relational and temporal modeling.

Technical Feasibility

The system is implemented using PyTorch Geometric, Scikit-learn, and Streamlit, and trained on an RTX 4060 GPU with 8GB VRAM and 24GB system memory. The dataset size and model complexity are well within the capabilities of this hardware, supporting mini-batch GNN training and explainability analysis.

The approach is scalable via neighborhood sampling and inductive learning, and fully reproducible using open-source tools.
